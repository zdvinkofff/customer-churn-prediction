# Customer Churn Prediction (Прогнозирование оттока клиентов)

Инструментарий на Python для автоматизированного анализа поведения клиентов интернет-провайдера и построения модели машинного обучения для предсказания риска их оттока.

## 🛠 Технологический стек:
- **Язык разработки:** Python
- **Анализ данных и предобработка:** Pandas, NumPy
- **Машинное обучение (ML):** Scikit-Learn (алгоритм Random Forest Classifier)
- **Визуализация и статистика:** Matplotlib, Seaborn

## 🚀 Реализованный функционал и этапы проекта:
1. **Генерация и очистка данных:** Создан реалистичный синтетический датасет на 3000 клиентов с факторами возраста, среднего чека, активности на сайте и количества звонков в техподдержку.
2. **Разведочный анализ данных (EDA):** Построены матрицы корреляции и графики распределения, математически доказавшие, что ключевым триггером оттока является высокая частота обращений в поддержку.
3. **Обучение модели ИИ:** Выборка разделена в пропорции 80/20. Обучена ансамблевая модель Случайного Леса (Random Forest).
4. **Оценка качества:** Модель достигла высокой общей точности (**Accuracy: ~74%**). Построена интерактивная матрица ошибок (Confusion Matrix) для оценки ложноположительных и ложноотрицательных прогнозов.
